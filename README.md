# MovieFinder

A modern **SwiftUI + Firebase** iOS app that lets users **search for movies**, view details, and save their favorites using the **OMDb API**.  
Built as part of a full-stack mobile development project demonstrating **SwiftUI architecture**, **Firebase Authentication**, **Firestore persistence**, and **API integration**.

---

## Features

- **Search Movies** by title via the OMDb API  
- **Movie Details** with poster, genre, director, and plot  
- **Favorites** — save and manage movies using Firebase Firestore  
- **User Authentication** — sign up, sign in, and sign out with FirebaseAuth  
- **Modern UI** — tab-based SwiftUI layout (Search | Favorites | Profile)  
- **Realtime Updates** — sync favorites instantly across devices
